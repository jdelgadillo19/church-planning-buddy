# Grapevine Brand Notes

## Direction

Grapevine should feel at home beside church production and ministry operations tools: calm, capable, polished, and Mac-native. The icon uses a rounded-square application tile, a vine that quietly forms a `G`, and connected grape nodes that also suggest workflows moving from Planning Center to service prep to ProPresenter.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Vineyard | `#123F35` | Primary brand field, headers, dark surfaces |
| Evergreen | `#0F2F2D` | Deep UI backgrounds and hover states |
| Grape | `#5B3AA1` | Accent, selection, graph/node emphasis |
| Bloom | `#8F5CFF` | Highlight for active states and icon depth |
| Leaf | `#34B979` | Success, connected/ready status |
| Gold | `#F1C766` | Build-ready handoff, caution-positive accents |
| Ivory | `#FFF7E7` | Warm surface contrast |
