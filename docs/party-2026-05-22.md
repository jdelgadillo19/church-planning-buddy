## User — MVP vision clarified

**User:**

> "church planning buddy" is ultimately intended to incorporate several features. MVP will require PCO integration (already existing) and Google Drive integration (half-set up).
>
> The first goal is to access the song scans, open an existing file in Google Drive called the "Get Ready Guide" and update it to remove contents of song scans from the previous week and copy/paste the song scan contents from the links in the individual songs within the plan ID submitted to the program. ## User — Five locked answers + signoff

1. **Roster:** In scope iff trivial.  
2. **Tagged blocks:** Future-proofing; not required for MVP.  
3. **Section delimiter:** New page + title; confidence via bold title + horizontal line.  
4. **Highest quality:** Always green; navigate subdirs; `blank` in title wins.  
5. **Partial failure:** Show candidate document titles; user selects.  

**Always require user signoff** before committing changes and exporting finished GRG.
